# 联机麻将 · 使用说明

四个人的大众麻将，谁没来就让电脑顶上。

## 一、跑起来（最省事的办法）

```
node game-hub/server/server.js
```

启动后终端会打印两行地址：

- 本机：`http://localhost:8787/`
- 局域网：`http://10.77.108.242:8787/`（同一 WiFi 下的手机、平板、别的电脑都用这个）

打开就是麻将桌。**不用装任何东西，不用 npm install，也不花钱。**

## 二、开一局

1. 第一个人进去点「创建房间」，屏幕上会出现一个 4 位房号（比如 `4QXF`）
2. 把房号念给朋友，他们打开同一个地址、点「加入房间」、输入房号
3. 人齐不全也没关系：点「开始游戏」时空着的座位会自动补上「电脑·东/南/西/北」
4. 中途有人掉线，重连会自动回到原座位；真的走了，那个座位由电脑接管，牌局不会坏

## 三、跨网络联机要什么

同一 WiFi（家里、宿舍、办公室）——现在的做法就够了，一分钱不花。

想让外地的朋友也进来，需要一台有公网 IP 的机器，也就是**云服务器**：

| 场景 | 大致配置 | 花费 |
| --- | --- | --- |
| 4 个人打麻将 | 1 核 1G / 2G，1~3 Mbps 带宽 | 约 10~40 元/月（新用户首年更便宜） |
| 想同时开好几桌 | 2 核 4G，5 Mbps | 约 80~150 元/月 |

部署就是把 `game-hub/server/` 整个目录传上去，执行 `node server.js`，再在安全组里放行 8787 端口（或者用 Nginx 转发到 80/443）。

## 四、规则说明

- 136 张牌，东南西北四人，标准大众麻将
- 只要「四组面子 + 一对将」就能胡，不算番
- 有碰、杠、自摸、点炮；**本玩法不含「吃」**
- 牌面按真牌绘制，出牌、碰、杠各有不同的牌声
